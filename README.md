# Нулевой пациент / Patient Zero

Собранная веб-игра для ВКонтакте и Одноклассников, раздаётся через GitHub Pages:
https://merrymaker14.github.io/patient-zero/

Здесь лежит только то, что скачивает браузер игрока. Исходники, дизайн-документы
и история разработки — в закрытом репозитории `html-games`; сюда сборку кладёт
`gta-zombie/tools/deploy-pages.mjs`.
